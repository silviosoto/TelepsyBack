CASOS DE USO DETALLADOS
=====================================================================

  ------------------------------
  CU-P-01 Registro de Paciente
  ------------------------------

Descripción: Permite crear una cuenta de paciente en el sistema.

Precondiciones: - El email no debe existir previamente.

Postcondiciones: - Usuario creado en estado Activo. - Email de
verificación enviado. - Registro auditado.

Flujo Principal: 1. El usuario envía nombre, apellido, email, contraseña
y teléfono. 2. El sistema valida formato de datos. 3. El sistema valida
unicidad de email. 4. Se encripta la contraseña. 5. Se crea entidad
Paciente. 6. Se registra evento UserRegistered. 7. Se envía email de
confirmación. 8. Se retorna respuesta 201 Created.

Reglas de Negocio: - Contraseña mínimo 8 caracteres. - Email
obligatorio. - Términos y condiciones obligatorios.

  -------------------------------------
  CU-P-02 Compra de Sesión Individual
  -------------------------------------

Descripción: Permite comprar una sesión individual con un psicólogo.

Precondiciones: - Psicólogo aprobado. - Slot disponible. - Paciente
autenticado.

Postcondiciones: - Orden creada. - Pago procesado. - Sesión
confirmada. - Comisión calculada (30%).

Flujo Principal: 1. Paciente selecciona psicólogo. 2. Selecciona tipo de
terapia. 3. Selecciona fecha y hora. 4. El sistema bloquea slot
temporalmente. 5. Se crea Order con estado Pending. 6. Se redirige a
pasarela de pago. 7. Pasarela envía webhook de confirmación. 8. Se
valida firma del webhook. 9. Se actualiza Order a Paid. 10. Se crea
entidad Session. 11. Se calcula comisión (precio * 0.30). 12. Se genera
registro financiero. 13. Se envía notificación.

Reglas de Negocio: - Comisión parametrizable (inicialmente 30%). - No se
crea sesión sin pago aprobado. - No doble reserva del mismo slot.

  ---------------------------------------
  CU-P-03 Compra de Paquete de Sesiones
  ---------------------------------------

Descripción: Permite comprar múltiples sesiones con 10% de descuento.

Reglas de Negocio: - Descuento fijo del 10%. - Créditos no
transferibles. - Créditos asociados al paciente y psicólogo.

  -------------------------------
  CU-P-04 Acceso a Videollamada
  -------------------------------

Descripción: Permite acceder a la videollamada integrada mediante Zoom.

Precondiciones: - Sesión pagada. - Acceso habilitado 10 minutos antes.

Flujo Principal: 1. Paciente presiona “Unirse”. 2. Sistema valida sesión
activa. 3. Sistema genera o consulta Meeting en Zoom. 4. Se obtiene
JoinURL segura. 5. Se registra evento SessionJoined.

Reglas: - URL firmada. - No persistir credenciales sensibles.
